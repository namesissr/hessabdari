# خزانه، چک و چاپ چک — راهنمای کاربری

## ۱. قبل از شروع: دو تعریف

1. **طرف حساب‌ها** (منوی «طرف حساب‌ها»): مشتری، تأمین‌کننده، کارمند، سهامدار. هر طرف حساب خودکار به یک تفصیلی حسابداری وصل می‌شود، پس گزارش بدهکاران/بستانکاران بدون کار اضافه ساخته می‌شود.
2. **بانک، صندوق و تنخواه** (منوی «بانک، صندوق و تنخواه»): هر حساب به یک حساب معین وصل می‌شود (بانک → ۱۱۰۱، صندوق → ۱۱۰۲، تنخواه → ۱۱۰۳) و موجودی‌اش از روی اسناد محاسبه می‌شود؛ مانده را دستی وارد نمی‌کنید.

## ۲. دریافت و پرداخت

هر سند خزانه دو بخش دارد:

- **از طریق**: پول از کجا آمد یا رفت — نقد، بانک، کارت، درگاه، چک جدید، یا واگذاری چک دریافتی. کارمزد بانکی هر ردیف جدا ثبت می‌شود.
- **بابت**: این پول بابت چه بود — تسویهٔ حساب یک مشتری، هزینه، پیش‌پرداخت، بدهی تأمین‌کننده و…

جمع دو بخش باید برابر باشد. با زدن «ذخیره و قطعی کردن»، سند حسابداری خودکار صادر می‌شود:

| حالت | ثبت حسابداری |
|---|---|
| دریافت بانکی ۵۰٬۰۰۰٬۰۰۰ با کارمزد ۵۰۰٬۰۰۰ بابت فاکتور مشتری | بدهکار: بانک ۴۹٬۵۰۰٬۰۰۰ + کارمزد بانکی ۵۰۰٬۰۰۰ — بستانکار: حساب دریافتنی مشتری ۵۰٬۰۰۰٬۰۰۰ |
| پرداخت هزینهٔ سرور با چک | بدهکار: هزینهٔ سرور — بستانکار: اسناد پرداختنی (چک) |
| انتقال بین دو حساب | بدهکار: حساب مقصد — بستانکار: حساب مبدأ (+ کارمزد) |

سند قطعی‌شده ویرایش نمی‌شود؛ برای اصلاح، «برگشت سند» بزنید و سند درست را ثبت کنید.

## ۳. چرخهٔ چک

**چک دریافتی**: نزد ما → واگذار به بانک → وصول / برگشت. از حالت «نزد ما» می‌توانید چک را خرج کنید (واگذاری به تأمین‌کننده) یا عودت دهید.

| رویداد | ثبت حسابداری |
|---|---|
| دریافت چک | بدهکار اسناد دریافتنی / بستانکار حساب دریافتنی مشتری |
| واگذاری به بانک | بدهکار چک‌های در جریان وصول / بستانکار اسناد دریافتنی |
| وصول | بدهکار بانک (منهای کارمزد) + کارمزد / بستانکار چک‌های در جریان وصول |
| برگشت | بدهکار حساب دریافتنی مشتری / بستانکار چک‌های در جریان وصول |
| خرج چک | بدهکار حساب پرداختنی تأمین‌کننده / بستانکار اسناد دریافتنی |

**چک پرداختی**: تحویل ذی‌نفع → پاس شدن / برگشت / عودت / ابطال.

| رویداد | ثبت حسابداری |
|---|---|
| صدور چک | بدهکار حساب پرداختنی (یا هزینه) / بستانکار اسناد پرداختنی |
| پاس شدن | بدهکار اسناد پرداختنی / بستانکار بانک |
| عودت یا ابطال | بدهکار اسناد پرداختنی / بستانکار حساب پرداختنی |

**چک تضمینی** اصلاً وارد حساب‌های اصلی نمی‌شود و فقط در حساب‌های انتظامی (۹۱۰۱/۹۲۰۱ و ۹۱۰۲/۹۲۰۲) ثبت و هنگام عودت برگشت می‌خورد.

سیستم فقط عملیات مجاز هر وضعیت را نشان می‌دهد؛ مثلاً چک پاس‌شده را نمی‌توان دوباره پاس کرد.

## ۴. چاپ چک — تنظیم یک‌بار برای همیشه

چاپ روی برگهٔ چک با مقیاس دقیق ۱:۱ انجام می‌شود. چون محل خانه‌ها در چک هر بانک کمی فرق دارد، یک‌بار برای هر بانک تنظیم می‌کنید:

1. **تنظیمات ← قالب چاپ چک**: یک قالب بسازید (مثلاً «چک بانک ملت») و عرض/ارتفاع برگه را وارد کنید (چک صیادی معمولاً حدود ۱۹۵×۸۵ میلی‌متر است؛ برگهٔ خودتان را با خط‌کش اندازه بگیرید).
2. **چاپ آزمایشی** را بزنید و صفحه را روی کاغذ سفید چاپ کنید. در پنجرهٔ چاپ مرورگر حتماً:
   - اندازهٔ کاغذ = همان اندازهٔ برگهٔ چک (یا A4)
   - حاشیه (Margins) = None
   - مقیاس (Scale) = ۱۰۰٪ و **نه** Fit to page
3. برگهٔ چک را روی کاغذ چاپ‌شده بگذارید و جلوی نور بگیرید. خطوط شبکه هر ۵ و ۱۰ میلی‌متر هستند.
4. در صفحهٔ قالب، فیلدی را که جابه‌جاست انتخاب کنید و روی تصویر، دقیقاً جای درست کلیک کنید (یا عدد میلی‌متری را تایپ کنید). اگر **همهٔ** نوشته‌ها به یک اندازه جابه‌جا بودند، فقط «جابه‌جایی کل افقی/عمودی» را تغییر دهید.
5. دوباره چاپ آزمایشی بگیرید تا دقیق شود. بعد از آن برای همهٔ چک‌های آن بانک همین تنظیم استفاده می‌شود.

**مبدأ مختصات گوشهٔ بالا-راست برگه است**: «فاصله از راست» و «فاصله از بالا».

فیلدهای قابل چاپ: سال/ماه/روز جدا (برای چک‌هایی که خانهٔ جدا دارند) یا تاریخ کامل، مبلغ به عدد، مبلغ به حروف، در وجه، شناسه/کد ملی گیرنده، بابت، شمارهٔ چک، شناسهٔ صیاد، محل صدور و یک یادداشت آزاد. هر فیلد را می‌توانید خاموش کنید (مثلاً اگر شمارهٔ چک از قبل روی برگه چاپ شده).

قبل از چاپ، یک کادر کنترل نشان داده می‌شود: تاریخ، در وجه، مبلغ به عدد و به حروف (و معادل تومان). اگر چکی قبلاً چاپ شده باشد، تعداد دفعات چاپ هشدار داده می‌شود تا چک دوباره چاپ نشود.

مبلغ به حروف با تست خودکار بررسی می‌شود (از «صفر» تا «بیلیون») تا متن چک هرگز اشتباه نوشته نشود.
