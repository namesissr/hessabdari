# نصب روی سرور مجازی با Docker — صفر تا صد

دامنه: `hessabdari.arzinoo.com` · سیستم‌عامل فرض‌شده: Ubuntu 22.04 یا 24.04 · مخزن: `https://github.com/namesissr/hessabdari.git`

معماری نصب:

```
اینترنت ──► Nginx (۸۰/۴۴۳ + گواهی SSL) ──► 127.0.0.1:3200 (کانتینر app) ──► کانتینر db (PostgreSQL)
                                                                              └─ volume: pgdata
```

کانتینر برنامه فقط روی `127.0.0.1` باز است؛ هیچ‌کس از بیرون مستقیم به آن و به دیتابیس دسترسی ندارد.

---

## گام ۱ — رکورد DNS

در پنل DNS دامنهٔ `arzinoo.com` یک رکورد بسازید:

| Type | Name | Value | Proxy |
|---|---|---|---|
| A | hessabdari | IP سرور | غیرفعال (DNS only) تا گواهی گرفته شود |

بررسی:

```bash
dig +short hessabdari.arzinoo.com
```

## گام ۲ — ورود به سرور و ایمن‌سازی اولیه

```bash
ssh root@SERVER_IP
```

```bash
apt update && apt -y upgrade && apt -y install git curl ufw
```

کلید SSH خود را اضافه کنید و ورود با رمز را ببندید (مهم — سرور دیگرتان از همین راه آلوده شد):

```bash
nano /etc/ssh/sshd_config
```

مقادیر زیر را تنظیم کنید و سپس سرویس را ری‌استارت کنید:

```
PermitRootLogin prohibit-password
PasswordAuthentication no
```

```bash
systemctl restart ssh
```

فایروال:

```bash
ufw allow OpenSSH && ufw allow 80/tcp && ufw allow 443/tcp && ufw --force enable
```

## گام ۳ — نصب Docker

```bash
curl -fsSL https://get.docker.com | sh
```

```bash
docker --version && docker compose version
```

> اگر دانلود ایمیج‌ها به‌خاطر تحریم/فیلتر شکست خورد، یک registry mirror ایرانی در `/etc/docker/daemon.json` با کلید `registry-mirrors` تنظیم کنید و `systemctl restart docker` بزنید. اگر `npm ci` هنگام build قطع شد، در سرور فایل `.npmrc` با `registry=https://registry.npmmirror.com` بسازید و آن را به مخزن اضافه کنید.

## گام ۴ — گرفتن کد

```bash
mkdir -p /opt && cd /opt && git clone https://github.com/namesissr/hessabdari.git && cd hessabdari
```

## گام ۵ — ساخت فایل `.env`

رمزها را تولید کنید:

```bash
echo "SESSION_SECRET=$(openssl rand -hex 32)"; echo "POSTGRES_PASSWORD=$(openssl rand -hex 16)"; echo "ADMIN_PASSWORD=$(openssl rand -base64 18)"
```

سپس فایل را بسازید و سه مقدار بالا را داخلش بگذارید:

```bash
nano /opt/hessabdari/.env
```

```
POSTGRES_PASSWORD=<مقدار تولیدشده>
SESSION_SECRET=<مقدار تولیدشده>
ADMIN_PASSWORD=<مقدار تولیدشده>
ADMIN_EMAIL=admin@arzinoo.com
SECURE_COOKIE=true
```

`ADMIN_PASSWORD` را جایی امن نگه دارید؛ فقط برای اولین ورود استفاده می‌شود.

```bash
chmod 600 /opt/hessabdari/.env
```

## گام ۶ — بالا آوردن سرویس

```bash
cd /opt/hessabdari && docker compose up -d --build
```

اولین build چند دقیقه طول می‌کشد. وضعیت و لاگ:

```bash
docker compose ps && docker compose logs -f --tail=50 app
```

در لاگ باید `All migrations have been successfully applied`، ساخته‌شدن ۱۸۹ حساب و `Ready` را ببینید. تست سلامت:

```bash
curl -s http://127.0.0.1:3200/api/health
```

خروجی باید `{"ok":true}` باشد.

## گام ۷ — Nginx و گواهی SSL

```bash
apt -y install nginx certbot python3-certbot-nginx
```

```bash
nano /etc/nginx/sites-available/hessabdari
```

```nginx
server {
    listen 80;
    server_name hessabdari.arzinoo.com;

    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:3200;
        proxy_http_version 1.1;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/hessabdari /etc/nginx/sites-enabled/ && nginx -t && systemctl reload nginx
```

گواهی Let’s Encrypt (پورت ۸۰ باید از بیرون باز باشد و DNS به سرور اشاره کند):

```bash
certbot --nginx -d hessabdari.arzinoo.com --agree-tos -m admin@arzinoo.com --redirect
```

تمدید خودکار از قبل با تایمر systemd فعال است:

```bash
systemctl list-timers | grep certbot
```

## گام ۸ — اولین ورود

آدرس `https://hessabdari.arzinoo.com` را باز کنید و با `ADMIN_EMAIL` و `ADMIN_PASSWORD` وارد شوید.

بلافاصله بعد از ورود:

1. **کاربران** → رمز مدیر را عوض کنید و برای هر نفر کاربر جدا با نقش مناسب بسازید (حسابدار / مدیر مالی / فقط مشاهده).
2. **شرکت‌ها** → مشخصات شرکت (نام ثبتی، شناسهٔ ملی، کد اقتصادی) را کامل کنید.
3. **سال و دوره مالی** → سال مالی جاری را بررسی یا اصلاح کنید.
4. **تفصیلی‌ها** → حساب‌های بانکی، صندوق، تنخواه و طرف‌حساب‌ها را وارد کنید.
5. **اسناد** → یک سند از نوع «افتتاحیه» برای مانده‌های اول دوره ثبت کنید.

## گام ۹ — پشتیبان‌گیری روزانه

```bash
mkdir -p /opt/backups && printf '%s\n' '#!/bin/sh' 'cd /opt/hessabdari && docker compose exec -T db pg_dump -U hesabdari hesabdari | gzip > /opt/backups/hesabdari-$(date +\%F).sql.gz' 'find /opt/backups -name "hesabdari-*.sql.gz" -mtime +30 -delete' > /opt/backup-hesabdari.sh && chmod +x /opt/backup-hesabdari.sh
```

```bash
(crontab -l 2>/dev/null; echo "30 2 * * * /opt/backup-hesabdari.sh") | crontab -
```

تست دستی:

```bash
/opt/backup-hesabdari.sh && ls -lh /opt/backups
```

بازگردانی یک نسخهٔ پشتیبان:

```bash
cd /opt/hessabdari && gunzip -c /opt/backups/hesabdari-1405-07-22.sql.gz | docker compose exec -T db psql -U hesabdari -d hesabdari
```

> نسخهٔ پشتیبان را به خارج از سرور هم منتقل کنید (مثلاً با `rsync` یا S3 ابرآروان).

## گام ۱۰ — به‌روزرسانی نسخه

```bash
cd /opt/hessabdari && git pull && docker compose up -d --build
```

migrationهای جدید هنگام بالا آمدن کانتینر خودکار اجرا می‌شوند و seed تکراری چیزی را بازنویسی نمی‌کند. قبل از هر به‌روزرسانی مهم، یک بار `/opt/backup-hesabdari.sh` را اجرا کنید.

## عیب‌یابی

| نشانه | بررسی |
|---|---|
| خطای ۵۰۲ در مرورگر | `docker compose ps` و `docker compose logs app` — احتمالاً کانتینر بالا نیامده |
| `Can't reach database server` | کانتینر db بالا نیست یا `POSTGRES_PASSWORD` در `.env` با چیزی که دیتابیس با آن ساخته شده فرق دارد |
| ورود انجام می‌شود ولی برمی‌گردد به صفحهٔ ورود | `SECURE_COOKIE=true` روی دامنهٔ بدون HTTPS؛ اول گواهی را بگیرید |
| `ADMIN_PASSWORD ... is required` در لاگ | مقدار `ADMIN_PASSWORD` در `.env` خالی یا کمتر از ۱۰ کاراکتر است |
| build در `npm ci` قطع می‌شود | دسترسی به registry؛ به یادداشت mirror در گام ۳ نگاه کنید |

دستورهای پرکاربرد:

```bash
cd /opt/hessabdari && docker compose logs -f --tail=100 app
```

```bash
cd /opt/hessabdari && docker compose restart app
```

```bash
cd /opt/hessabdari && docker compose exec db psql -U hesabdari -d hesabdari -c "select count(*) from vouchers;"
```
